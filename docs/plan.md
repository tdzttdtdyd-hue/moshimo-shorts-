# 企画書：もしも地球の自転が突然止まったら

- 尺：37.0 秒（1110 フレーム / 30fps）／ 1080×1920
- ナレーション・BGM なし。効果音は FFmpeg で合成したもののみ使用
- テロップ文言の正本：`src/script.ts`

## 使用する数値と根拠

| 表示 | 根拠・計算 |
|---|---|
| 赤道の自転速度 **時速 約1,700km** | 赤道一周 40,075km ÷ 自転周期 23.93 時間 ≒ 1,674 km/h |
| **新幹線の約5倍** | 新幹線の最高営業速度 320 km/h。1,674 ÷ 320 ≒ 5.2 |
| 日本（東京・北緯35.7°）**時速 約1,360km** | 1,674 × cos(35.7°) ≒ 1,674 × 0.812 ≒ 1,359 km/h |
| **音速を超える** | 音速 約1,225 km/h（15℃）。1,359 > 1,225 |
| 1日の長さ **約365日** | 自転が止まると、太陽に対する向きは公転だけで変わる。太陽が空を一周するのに 1 年かかるので、1日 = 約 1 年 |
| **昼が約半年・夜が約半年** | 上記より、同じ地点の昼と夜はそれぞれ約半年続く |
| 海が両極へ集まり赤道に大陸 | 遠心力で赤道側に盛り上がっていた海水（赤道半径と極半径の差 約21km）が、自転停止で極側へ移動するという試算（ESRI の Witt による分析などで紹介されている） |
| **100年で 約2ミリ秒** | 潮汐摩擦などにより、1日の長さは 100 年で約 1.7〜2.3 ミリ秒ずつ長くなっている（観測・理論値） |

表現上の注意
- 津波の高さ、気温などは試算によって幅が大きいので、具体的な数値は出さない
- 「止まることはない」は「急に止まることは まずない」と表現する（物理的に急停止させる仕組みが存在しないため）

## テロップ通読チェック（映像なしで読んだ場合）

> もしも地球の自転が突然止まったら…？
> 【0秒後】地面は止まっても、人と空気は動き続ける。時速約1,700km、新幹線の約5倍。
> 【0秒後｜日本】日本でも時速約1,360km。音速を超える暴風。
> 【数分後】海も止まれず、巨大な津波が陸をおそう。
> 【やがて】遠心力がなくなり、海が北極・南極へ。赤道に巨大な大陸が出現。
> 【そして】1日の長さが約365日。昼が約半年、夜が約半年。
> 昼側は灼熱。夜側は極寒。
> 【新しい地球】人が住めるのは昼と夜の境目だけ。
> でも安心。地球が急に止まることはまずない。
> 【実は…】自転は少しずつ遅くなっている。100年で約2ミリ秒。
> あなたなら、昼と夜どっちに住む？

→ 問い（フック）→ 直後 → 数分後 → 長期 → 結論 → 安心オチ → 豆知識 → 問いかけ、の順で、映像なしでも話がつながることを確認した。

制作中に検証で見つかり修正したこと
- 長いテロップと 4 桁の数値が横幅（860px）を超えていた → 文字数からサイズを自動調整する処理を追加
- 効果音のピークが -3.8 dBFS だった → 全体のゲインを下げて -9 dBFS に
- 地球の面の間の隙間、昼夜シーンが暗すぎる、津波が小さい、ラストの惑星の色 → 目視確認で修正

## v2：地球・風景・キャラクターの品質向上

- 地球：細かい地形メッシュ（標高・緯度・湿度で 砂浜/草原/森/砂漠/ツンドラ/岩山/雪 を塗り分け）、深さで色が変わる光沢のある海、雲のレイヤー、大気のリムライト、夜側の街明かり、星雲の背景と天の川
- 風景：空のグラデーションと太陽光、遠景の山並み、立体の雲、インスタンス化した木（広葉樹・針葉樹・桜）と草、切妻屋根・窓・煙突のある家、センターラインと歩道のある道路、窓テクスチャ付きのビル、津波のしぶき、オーロラ
- キャラクター：顔を描かない約7.5頭身の人型。関節（肩・肘・股・膝・背骨・首）でポーズを付け、感情は動き（手を振る／逃げる／吹き飛ぶ／汗をぬぐう／震える／考える）で表現
