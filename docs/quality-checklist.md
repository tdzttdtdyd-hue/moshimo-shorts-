# 書き出し前の確認リスト（毎回これを通してから書き出す）

自動の検証（verify.mjs）は「止まって見える場面・テロップの位置・書体」しか見ない。
動きや物の当たりは自動では分からないので、場面ごとに試し画像を見て、下の項目を目で確かめる。

## 1. 試し画像の撮り方
- 全場面について、場面の **はじめ・まん中・おわり** の3コマを撮る（`scripts/stills.mjs`）
- 人や小物が小さいときは、その部分を **切り出して拡大** して見る（ffmpeg の crop）

## 2. 人の動き
- [ ] 歩いている人は **位置が進んでいる** か（その場で足踏みしていないか）
  - 歩く人は `src/three/Walk.ts` の `walkAlong` を使う（進んだ距離に合わせて足を出すので、足が滑らない）
- [ ] 体の向きと進む向きが合っているか
- [ ] 物を持つ動きは、手と物がつながっているか（宙に浮いた物・手から離れた道具がないか）
  - 手に持つ物は Human の `rHand` / `lHand` に入れる
- [ ] スポーツなどの一連の動き（投げる→打つ など）が、順番どおりにつながっているか

## 3. 物の当たり・位置
- [ ] 人の体が机・壁・家具・木などに **めり込んでいない** か（家具の範囲と人の立ち位置を数字で確かめる）
- [ ] 座っている人がいすやソファから **浮いていない／沈んでいない** か（腰の高さ ≒ 座面の高さ）
- [ ] 人や物が水の上・空中に **浮いていない** か（地面の高さを確かめる）

## 4. 物理・リアリティ
- [ ] 飛ぶ物・落ちる物は、重力（と必要なら空気の抵抗）で計算した動きか
- [ ] 破裂・崩れるなどの出来事は、前ぶれ → 本番 → あと（残骸・こぼれた物）まで描けているか
- [ ] 出す数字は計算や資料で確かめたか（台本の冒頭コメントに計算を書く）

## 5. 画面の見やすさ
- [ ] 主役（人・物）がカードやテロップに隠れていないか
- [ ] 主役が画面の端で切れていないか
- [ ] 指し示す吹き出しが、正しい物を指しているか

## 6. 書き出し後
- [ ] verify.mjs の項目がすべて ✅
- [ ] 全体のコマ一覧（contact_sheet.png）を見て、1〜5 をもう一度ざっと確認
