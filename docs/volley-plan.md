## 想定と数値の根拠

「威力」＝ボールの速さとし、1本目 時速110km から 1本ごとに2倍。n本目の球速 = 110 × 2^(n−1) km/h。

| 本数 | 球速 | 比較 |
|---|---|---|
| 1 | 110km/h | 男子トップ選手の強打（おおむね 100〜130km/h） |
| 2 | 220km/h | プロ野球の最速球 約165km/h より速い |
| 3 | 440km/h | 新幹線の最高営業速度 約320km/h より速い |
| 4 | 880km/h | 旅客機の巡航速度 約900km/h なみ |
| 5 | 1,760km/h | 音速 約1,225km/h（15℃）を超える → 衝撃波 |
| 8 | 14,080km/h | ライフル弾 約3,000km/h の約5倍 |
| 9 | 28,160km/h | 地表近くの人工衛星（周回速度 約7.8km/s ≒ 約28,000km/h）と同じ。周回にかかる時間は約90分 |

- 6〜8本目の「摩擦で燃える」は、極超音速で空気が圧縮・加熱される現象（隕石が光るのと同じ）を表現したもの
- 9本目の周回は「空気抵抗を無視した場合」の計算（画面に想定として表示）
- オチの判定：打ったボールが自分たちのコートに落ちたので、相手チームの得点。24-24 から 24-25 となり、相手がセットを取る

- 球速カードは前の球速から数え上げ（例：2本目は 110→220km/h）、「前の2倍」のバッジを付ける。単位は km/h

## テロップ通読チェック

> もしも1回ごとにスパイクの威力が2倍になっていったら？
> 1本目は、ふつうのスパイク（時速110km）。→ 2本目、レシーブが弾き飛ばされる（220km）。→ 3本目、受けた選手ごと吹っ飛ぶ（440km）。→ 4本目、体育館の床に穴があく（880km）。→ 5本目、音の壁を突破（1,760km）。→ 6〜8本目、ボールが摩擦で赤く燃えはじめる（14,080km）。→ 9本目、打ちそこねてボールが宇宙へ、地球を1周しはじめる（28,160km＝人工衛星の速さ）。→ 約90分後、戻ってきて自分のコートに落ちた。→ 判定は相手チームに1点、セットを落とした。最強のスパイクは、ただの失点でした。

映像なしでも、エスカレート → 宇宙 → 戻ってくる → 失点のオチ、の順で話がつながる。
